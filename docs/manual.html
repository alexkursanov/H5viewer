Введение

H5 Reader — это программа для просмотра и анализа HDF5 файлов с данными компьютерного моделирования кардиомиоцитов. Программа позволяет визуализировать результаты моделирования, анализировать ключевые характеристики и экспортировать данные.

📂 Просмотр файлов

Открывайте и просматривайте структуру HDF5 файлов

📊 Графики

Стройте графики зависимостей переменных от времени

🔬 Анализ

Анализируйте APD, силу и кальциевые характеристики

💾 Экспорт

Сохраняйте результаты в формате Excel

Установка

Требования

  • Python 3.8 или выше
  • Операционная система: Windows, Linux, macOS

Установка из исходного кода

  1. Склонируйте репозиторий или скачайте исходный код
  2. Установите зависимости:
pip install -r requirements.txt
  1. Запустите программу:
python main.py

Основные функции

Открытие файлов

Способы открытия:
  • Меню: File → Open H5 File
  • Горячая клавиша: Ctrl+O
  1. В диалоговом окне выберите файл с расширением .h5 или .hdf5
  2. Файл добавится в список файлов слева
  3. Структура файла отобразится в дереве
  4. Информация о параметрах появится внизу панели

Структура HDF5 файла

После открытия файла в левой панели отображается дерево:

H5 Structure:
├── currents         (токи ионов)
│   ├── i_CaL        (L-тип Ca тока)
│   ├── i_K1         (внутриклеточный K ток)
│   ├── i_Na         (Na ток)
│   └── ...
├── forces           (силы)
│   ├── F_CE         (активная сила)
│   ├── F_PE         (пассивная сила)
│   └── ...
├── parameters       (149 параметров модели)
└── variables       (переменные состояния)
    ├── V            (мембранный потенциал)
    ├── Cai          (внутриклеточный Ca)
    └── ...

Вкладка "All Cycles"

Построение графиков для всех циклов моделирования.

Элементы управления

Элемент Описание
Mode: Single Режим одиночного графика
Mode: Multiple Режим наложения графиков
Show Stimuli Показать точки стимуляции
Clear Chart Очистить график
Up/Down Sliders Границы оси X

Вкладка "Last Cycle"

Построение графиков для последнего цикла (до 7 графиков одновременно).

Элементы управления

Элемент Описание
Add Lines Добавить выбранные datasets на график
Remove Selected Удалить выбранный элемент
Clear Selection Очистить весь выбор
Total Clear Очистить все графики
Ограничение: Максимум 7 графиков одновременно

Вкладка "Dependencies"

Таблица и графики зависимостей характеристик от частоты стимуляции.

Доступные характеристики

  • Voltage: V_max, V_min, APD20, APD50, APD90, tV_max
  • Force: FXSE_max, FXSE_min, DF_max, DF_min
  • Calcium: Cai_max, Cai_min, Cai_D10, Cai_D50, Cai_D90

Вкладка "Integrals"

Расчет интегралов токов кальция.

Рассчитываемые интегралы

Интеграл Описание
Int{i_relSR} Ток высвобождения из JSR
Int{i_leak} Ток утечки
Int{i_up} Ток поглощения
Int{i_CaL} L-тип Ca тока
Int{i_NaCa} Na/Ca обменник

Устранение неполадок

Файл не открывается

  • Убедитесь, что файл имеет расширение .h5 или .hdf5
  • Проверьте целостность файла

График не строится

  • Убедитесь, что выбраны данные в дереве
  • Проверьте, что dataset содержит числовые данные

Ошибка сохранения в Excel

  • Закройте файл Excel, если он открыт
  • Проверьте доступность места на диске
