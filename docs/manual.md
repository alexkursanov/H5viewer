## Введение

H5 Reader — это программа для просмотра и анализа HDF5 файлов с данными компьютерного моделирования кардиомиоцитов. Программа позволяет:

- Открывать и просматривать структуру HDF5 файлов
- Строить графики зависимостей переменных от времени
- Анализировать характеристики (APD, сила, кальций)
- Рассчитывать интегралы кальция
- Сохранять результаты в формате Excel

## Установка

### Требования

- Python 3.8 или выше
- Операционная система: Windows, Linux, macOS

### Установка из исходного кода

1. Склонируйте репозиторий или скачайте исходный код
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Запустите программу:

```bash
python main.py
```

### Зависимости

- PyQt6 >= 6.5.0 — графический интерфейс
- h5py >= 3.9.0 — работа с HDF5 файлами
- numpy >= 1.24.0 — математические вычисления
- pandas >= 2.0.0 — работа с таблицами
- matplotlib >= 3.7.0 — построение графиков
- openpyxl >= 3.1.0 — экспорт в Excel
- scipy >= 1.11.0 — научные вычисления

## Основные функции

### Открытие файлов

**Меню: File → Open H5 File**

или

**Горячая клавиша: Ctrl+O**

1. В диалоговом окне выберите файл с расширением `.h5` или `.hdf5`
2. Файл добавится в список файлов слева
3. Структура файла отобразится в дереве
4. Информация о параметрах (cycle length, frequency, number of cycles) появится внизу панели

### Просмотр структуры файла

После открытия файла в левой панели отображается дерево:

```
H5 Structure:
├── currents
│   ├── i_CaL
│   ├── i_K1
│   ├── i_Na
│   └── ...
├── forces
│   ├── F_CE
│   ├── F_PE
│   └── ...
├── parameters
│   └── (149 параметров)
└── variables
    ├── V
    ├── Cai
    └── ...
```

Щелчок по элементу отображает график на текущей вкладке.

### Вкладка "All Cycles" (Все циклы)

Построение графиков для всех циклов моделирования.

**Элементы управления:**

| Элемент | Описание |
|---------|-----------|
| **Mode: Single** | Режим одиночного графика (очистка при новом построении) |
| **Mode: Multiple** | Режим наложения графиков |
| **Show Stimuli** | Показать точки стимуляции |
| **Clear Chart** | Очистить график |
| **Up Slider** | Верхняя граница оси X |
| **Down Slider** | Нижняя граница оси X |

**Построение графика:**

1. Перейдите на вкладку "All Cycles"
2. Выберите dataset в дереве слева (переменные, токи или силы)
3. График отобразится на canvas

**Режимы отображения:**

- **Single** — каждый новый график заменяет предыдущий
- **Multiple** — графики накладываются друг на друга

**Отображение стимулов:**

При включенной опции "Show Stimuli" треугольниками отмечаются моменты стимуляции.

### Вкладка "Last Cycle" (Последний цикл)

Построение графиков для последнего цикла (до 7 графиков одновременно).

**Элементы управления:**

| Элемент | Описание |
|---------|-----------|
| **Список выбранных** | Показывает выбранные datasets |
| **Remove Selected** | Удалить выбранный элемент из списка |
| **Clear Selection** | Очистить весь выбор |
| **Add Lines** | Добавить выбранные datasets на график |
| **Total Clear** | Очистить все графики |

**Построение графиков:**

1. Перейдите на вкладку "Last Cycle"
2. Выберите datasets в дереве слева (кликая по ним)
3. Нажмите "Add Lines"
4. Графики отобразятся на canvas с разными цветами

**Ограничения:**

- Максимум 7 графиков одновременно
- Данные масштабируются по общей оси Y

### Вкладка "Dependencies" (Зависимости)

Таблица и графики зависимостей характеристик от частоты стимуляции.

**Элементы управления:**

| Элемент | Описание |
|---------|-----------|
| **New Data** | Рассчитать зависимости для выбранных файлов |
| **Sort on Hz** | Сортировать по частоте |
| **Sort on CL** | Сортировать по длительности цикла |
| **Save to XLS** | Сохранить таблицу в Excel |
| **X Axis** | Выбор оси X |
| **Characteristics** | Выбор характеристики для графика |
| **Draw Chart** | Построить график |

**Доступные характеристики:**

- **Voltage**: V_max, V_min, APD20, APD50, APD90
- **Force**: FXSE_max, FXSE_min, FXSE_D50, DF_max, DF_min
- **Calcium**: Cai_max, Cai_min, Cai_D10, Cai_D50, Cai_D90

### Вкладка "Integrals" (Интегралы)

Расчет интегралов токов кальция.

**Элементы управления:**

| Элемент | Описание |
|---------|-----------|
| **New Data** | Рассчитать интегралы |
| **Sort on Hz** | Сортировать по частоте |
| **Sort on CL** | Сортировать по длительности цикла |
| **Save to XLS** | Сохранить таблицу в Excel |
| **X Axis** | Выбор оси X |
| **Integrals** | Выбор интеграла для графика |
| **Draw Chart** | Построить график |

**Рассчитываемые интегралы:**

- Int{i_relSR} — интеграл тока высвобождения из JSR
- Int{i_relcyt} — интеграл тока высвобождения в цитоплазму
- Int{i_relSS} — интеграл тока высвобождения в SS
- Int{i_leak} — интеграл тока утечки
- Int{i_up} — интеграл тока поглощения
- Int{i_xfercyt} — интеграл тока трансфера в цитоплазму
- Int{i_xferSS} — интеграл тока трансфера в SS
- Int{i_bCa} — интеграл фонового Ca тока
- Int{i_pCa} — интеграл Ca насоса
- Int{i_NaCain} — интеграл Na/Ca обменника (входящий)
- Int{i_NaCaout} — интеграл Na/Ca обменника (исходящий)
- Int{i_NaCatotal} — суммарный интеграл Na/Ca
- Int{i_CaLcyt} — интеграл L-типа Ca тока в цитоплазму
- Int{i_CaLSS} — интеграл L-типа Ca тока в SS

## Сохранение данных

### Меню File → Save Data to XLS

| Пункт | Описание |
|-------|-----------|
| **Save All Cycles** | Сохранить все данные (время + все datasets) |
| **Save First Cycle** | Сохранить данные первого цикла |
| **Save Last Cycle** | Сохранить данные последнего цикла |
| **Save Parameters** | Сохранить параметры модели |
| **Save Vars (1st and Last)** | Сохранить первые и последние значения переменных |
| **Save Charts to XLS** | Сохранить графики в PDF + параметры в Excel |

### Сохранение таблиц на вкладках

На вкладках "Dependencies" и "Integrals" кнопка **Save table to XLS** сохраняет текущую таблицу.

## Устранение неполадок

### Файл не открывается

- Убедитесь, что файл имеет расширение `.h5` или `.hdf5`
- Проверьте целостность файла

### График не строится

- Убедитесь, что выбраны данные в дереве
- Проверьте, что dataset содержит числовые данные

### Ошибка сохранения в Excel

- Закройте файл Excel, если он открыт
- Проверьте доступность места на диске
